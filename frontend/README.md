# RealEyes Frontend (Dashboard)

This directory contains the Next.js 16 (React 19) visual dashboard for RealEyes.

## Quick Start

For full project setup instructions, architecture documentation, and system requirements, please refer to the **[Main RealEyes README](../../README.md)**.

### Running Locally

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```

The app will be available at [http://localhost:3000](http://localhost:3000). Ensure the Flask backend is running on `http://127.0.0.1:5001`.
